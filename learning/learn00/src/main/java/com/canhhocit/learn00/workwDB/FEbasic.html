🔥 CÔNG THỨC FE GỌI API - 4 THAO TÁC CƠ BẢN 🔥

1️⃣ LẤY DỮ LIỆU (GET)
// Công thức: const response = await fetch('URL'); const data = await response.json(); // Ví dụ thực tế: async function getData() { const response = await fetch('http://localhost:8080/api/users'); const users = await response.json(); console.log(users); // In ra danh sách }
BE trả về JSON: [{"userID":1,"name":"An","address":"HN"}]
2️⃣ TẠO MỚI (POST)
// Công thức: const response = await fetch('URL', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(duLieu) }); // Ví dụ thực tế: async function createData() { const newUser = { name: "Bình", address: "HCM" }; const response = await fetch('http://localhost:8080/api/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(newUser) }); const result = await response.json(); console.log("Đã tạo:", result); }
Gửi lên BE: {"name":"Bình","address":"HCM"}
BE trả về: {"userID":2,"name":"Bình","address":"HCM"}
3️⃣ CẬP NHẬT (PUT)
// Công thức: const response = await fetch('URL/id', { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(duLieuMoi) }); // Ví dụ thực tế: async function updateData() { const id = 1; const updated = { name: "An Updated", address: "DN" }; const response = await fetch(`http://localhost:8080/api/users/${id}`, { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(updated) }); const result = await response.json(); console.log("Đã cập nhật:", result); }
Gửi lên BE: {"name":"An Updated","address":"DN"}
BE trả về: {"userID":1,"name":"An Updated","address":"DN"}
4️⃣ XÓA (DELETE)
// Công thức: const response = await fetch('URL/id', { method: 'DELETE' }); // Ví dụ thực tế: async function deleteData() { const id = 1; const response = await fetch(`http://localhost:8080/api/users/${id}`, { method: 'DELETE' }); console.log("Đã xóa ID:", id); }
BE xóa: User có ID = 1
Response: Thường trả về status 200/204 (không có body)

📋 BẢNG TÓM TẮT

Method Mục đích URL Body
GET Lấy dữ liệu /api/users Không có
POST Tạo mới /api/users JSON data
PUT Cập nhật /api/users/1 JSON data
DELETE Xóa /api/users/1 Không có
